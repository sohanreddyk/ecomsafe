# experiments/

**Scaffold for upcoming implementation. No experimental results currently exist.**

This directory will hold outputs and logs from planned experiments, starting with the first-cycle pilot:

- **Contents:** evaluation outputs (ROC AUC per threat class, early-detection rate before turn 5, false-positive rate on benign dialogues, p50/p95 per-turn latency) for EcomSafe and the four baselines.
- **Logs:** run logs, each recording the config and seed it used.

During the first cycle, pilot outputs are **pipeline sanity checks only**. With roughly 10 conversations per attack type, they are not reportable findings.
